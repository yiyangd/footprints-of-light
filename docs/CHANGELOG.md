# 更新记录

## v0.3 主页“光之地图”（2026-11-20）
- 新增主页（`home/`）：先是封面（和序章原来的标题页一样：书名、诗 77:19、语言选择、“开始旅程”），点“开始旅程”进入“光之地图”
- 光之地图：古代世界地图 + 时间之河，66 卷书是 66 盏灯，41 张场景地图是地图上的 41 个点。这是游戏的目录
- 三种灯：主线 12 卷在河心，并行 6 卷贴着主线（四福音是四盏并排的灯），插入 48 卷挂在河的两边
- 点一盏灯：卡片显示年代、挂在主线的哪里、走过哪些地方，地图飞到那里并用一串脚踪连起来；点一个地点：显示今天在哪里、哪些书卷走过这里。耶路撒冷列出十个时代
- 目前只有创世记的灯能进（序章）；走完序章，创世记的灯点着，伊甸算“走过”，河上铺出第一段金色的脚踪。其余 65 卷显示“建造中”
- 新增 `content/timeline.json`（12 季、66 卷、41 张地图）和 `content/home-ui.json`；`home/` 里 `npm run validate` 检查数据
- 底图的海岸线来自 Natural Earth（公有领域），由 `home/tools/make-basemap.mjs` 生成；河和湖是手工描的简化线
- 网站结构变了：`/` 是主页，`/prologue/` 是序章。序章里加了“回到光之地图”的按钮（只有从主页进来才显示）；从地图进序章时，开始页不再重复大标题、经文和语言选择，只留“序章 · 起初”、按钮和操作说明
- 网址带 `#map` 时主页直接显示地图（从序章回来、或在地图上刷新时用）；点左上角的书名回到封面
- 两种语言、手机竖屏和横屏都检查过；语言设置和序章共用

## v0.2 双语（2026-11-20）
- 放上 GitHub，并用 GitHub Pages 发布：推送到 main 就自动打包、更新网站（`.github/workflows/deploy.yml`）
- 游戏改名为《光之踪迹》Footprints of Light（诗 77:19）；工作名《光之约》Covenant of Light 和已有游戏的名字太接近。标题页经文换成诗 77:19
- 两种语言模式：English（经文 ESV）和 English + 中文（ESV + 和合本），默认双语；标题页选择，游戏里用地球按钮或 L 键切换，自动记住
- 所有内容改成 `{ en, zh }`；经文出处统一写成 `Gen 1:3`，显示为 Genesis 1:3 / 创 1:3；旧存档自动转换
- 每段经文标明译本（ESV / 和合本）；标题页和图鉴“经文”页显示 Crossway 要求的版权声明
- 英文字体：EB Garamond（经文、标题）、Nunito（界面）；ESV 里的 LORD 用小型大写字母显示
- 手机竖屏：右上角按钮只留图标，时间线移到按钮下面；横屏：字幕更紧凑，剧情时收起时间线，提示放在摇杆和跳跃键中间
- 修正陶片《“好”和“甚好”》：第二日其实没有“神看着是好的”，创世记第 1 章是六次“好”，第七次是“甚好”
- 新增 `npm run count:esv`（统计 ESV 节数和文字比例）、`npm run export`（导出 JSON）
