## 英文经文改用 BSB；经文一节都不跳过（2026-11-21）
带领人定了两件事：英文经文从 ESV 换成公有领域的 BSB（Berean Standard Bible）；经文一节都不跳过。
- **玩家会看到的变化**：所有英文经文换成了 BSB 的译文，字幕和图鉴里经文旁的标签从 ESV 变成 BSB，开始页、主页封面和图鉴“经文”页下面的版权声明换成了 BSB 的署名。中文经文没有动
- BSB 的原文（创世记全卷 1533 节和诗 77:19）存进了 `content/scripture/bsb.json`，是用程序从官方文本生成的
- 新增 `npm run fill:scripture`：写好出处，程序把英文原文填进去。现有的 38 行经文就是这样换的，没有手抄
- `npm run validate:content` 现在会核对每一行英文经文都和 BSB 原文一字不差，改动一个词都会报错，网站就不会发布
- `npm run count:esv` 换成了 `npm run count:verses`：不再数 ESV 的额度（BSB 没有上限），改成列出每一章的经文范围里还缺哪些节。现在第 1 章 34 节里有 28 节，第 2 章 23 节里有 13 节，一共还缺 16 节
- 陶片和信物的说明里引用的英文经文（6 处）也改成了 BSB 的说法；中文没有动
- `AGENTS.md` 第 1、2 条照新的规矩重写了。小样（`/prologue/`）没有动，里面还是 ESV
- 这次还没有做：把缺的 16 节补进剧情。英文随时可以填，中文要先定用哪一份文本（见 `docs/STATUS.md` 的“还没定”）
- 自动测试从 88 个变成 96 个

## 修正：鱼和走兽刚出现时的位置（2026-11-21）
这一条只改正式工程（`/play/`）。小样（`/prologue/`）没有动，所以从这里开始，两边在第五日、第六日之后有意地不一样了。
- 鱼（第五日）：每条鱼的第一次跳跃现在也在它自己的水域里。以前起跳点和落水点一开始都是 (0, 0)，第一次跳跃发生在地图正中央的陆地上——那里的地面有 2 米多高，鱼其实是在地底下跳，谁也看不见。看得见的变化是：第五日一到，小湖里的三条鱼两三秒之内就先后跳出来，以前要等六到九秒
- 走兽（第六日）：出现以后留在各自的“家”附近吃草、走动。以前每只动物“想去的地方”一开始也是 (0, 0)，所以一出现就集体朝地图正中央走（有的一直走到那里），到了才各自回家
- 鱼只在水里跳：修上面那条的时候发现，七条鱼里有四条的“水域”本身就压在陆地上（小样里就是这样）——西边那片整个在山坡上，鱼大多在地底下跳，看不见；南边那片在起点旁边的沙滩上，鱼是从沙子里跳出来的；北边那片大半在岸上，东边那片小半在岸上。小湖里的鱼大约九次里也有一次落到岸上。现在：
  - 西、南、北三片水域往海里挪了（西 14 米、南 14 米、北 7 米），东边和小湖没有挪
  - 每次挑起跳点和落水点时都量一下那里的水深，起跳、半路、落水三处都要是水（水底至少比水面低 0.3 米），挑到岸上就重挑
  - 鱼的水域和选点的计算搬到了 `src/world/fish-spots.ts`，新增 7 个自动测试（`npm test`）：每片水域各挑 5000 次，没有一次碰到岸。以后改了地形或者挪了水域，测试会提醒
- 草、树、动物出生的位置没有变（没有动带种子的随机数）
- 这次没有修、留给带领人决定的一件事：家在 (14, 30) 的三只绵羊出生在河里，一直站在水下不动（小样里就是这样）。要修就得挪它们的家或者出生的位置，见 `docs/STATUS.md` 的“还没定”

## v0.4 正式工程起步：M0 第 1 步（2026-11-21）

- 新增 `.github/workflows/check.yml`：开 PR 时自动测试、打包一遍，合并之前就能知道会不会出错
- 开始页最下面的小字从“可玩小样 v0.2”改成“序章 v0.4”，方便分辨打开的是哪一版
- 新增 `tools/compare-prototype/`：把小样和正式工程逐帧同步地各跑一遍再比较。三种屏幕 × 两种语言下，游戏状态全部一致，游戏里的截图最多差 12 个像素
- 打包时指定了和小样一样宽的浏览器范围（`vite.config.ts`），避免样式被改成旧 iPhone / iPad 不认识的写法
