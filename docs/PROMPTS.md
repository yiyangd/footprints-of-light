# 《光之踪迹》提示词包

用法：
- 给 Codex 的提示词（M0–M10、新章节模板、修 bug 模板）：在 Codex 里打开这个仓库，一次复制一段。
- 给 Claude / ChatGPT 的“章节策划提示词”：每做一个新章节时用一次，得到方案和 JSON 初稿后，必须人工逐字核对经文。
- 一次只做一个里程碑；做完先在电脑和手机上各玩一遍，再做下一个。
- **2026-11-21 起英文经文改用 BSB（公有领域），并且经文一节都不跳过。** 下面的提示词是那之前写的：里面的 ESV 请读作 BSB，`npm run count:esv` 请读作 `npm run count:verses`，500 节的上限不再适用。现在的规矩以 `AGENTS.md` 第 1、2 条为准。

## M0 起步：把小样变成正式工程

```
先阅读 AGENTS.md、docs/设计方案.md、prototype/src/ 里的小样源码（index.html、main.js、content.js）、content/episodes/ 里的两个 JSON。

任务：
1. 用 Vite + TypeScript + Three.js 初始化工程。package.json 提供 dev、build、preview、test、validate:content、count:esv 脚本；安装 three、zod、vitest。
2. 按 AGENTS.md 的目录结构，把小样的代码拆成模块（core / world / player / story / collect / episodes），画面和玩法保持和小样一致。
3. 小样里写死的剧情文字、陶片、信物、彩窗数据，全部改为从 content/episodes/gen-01-creation.json 和 gen-02-eden.json 读取。所有给玩家看的文字都是 { en, zh }。
4. 双语：把小样的语言系统搬进 src/core/i18n.ts —— 只有 en（English）和 bi（English + 中文）两种模式，默认 bi；所有文字同时输出英文和中文两个 span，en 模式用 CSS 隐藏中文，切换不用重画；选择存在 localStorage；界面上的固定文字也移到 content/ui.json。
5. 写 src/content/schema.ts（zod）和 scripts/validate-content.ts：kind 写错、缺少出处、坐标格式不对、某段文字缺 en 或 zh 时，报出清楚的中文错误（哪个文件、哪一项）。
6. 写 scripts/count-esv.ts 和 npm run count:esv：统计用了多少节 ESV 经文（上限 500）和经文占全部文字的比例（参考 prototype/count-esv.mjs）。
7. 仓库里已经有 .github/workflows/deploy.yml：现在它打包主页 home/（发布在网站最外层）和序章 prototype/（发布在 /prologue/）。新的 Vite 工程做好后，把序章那一部分换成构建 Vite 工程并发布到 /play/（Vite 的 base 设成 "./"），并把 content/timeline.json 里创世记的 play.url 改成 "./play/"；主页 home/ 保持不动。发布成功前不要删掉 prototype/。
8. 写中文 README.md：怎么安装 Node.js、怎么运行、怎么在手机上测试。

先列出你的计划（不超过 10 条），再开始改代码。

验收：
- npm run dev 打开后，能完整玩一遍创造七日和伊甸园，和小样一致；English 和 English + 中文两种模式都正常，标题页和图鉴里有 ESV 版权声明
- npm run build、npm test、npm run validate:content 全部通过
- 把 JSON 里某个 kind 故意改错，validate:content 会指出是哪个文件、哪一项
```

## M1 手感：走、跑、跳、滑翔

```
目标：在电脑和手机上都像在云上散步一样舒服。

任务：
1. 角色控制：加速、减速要平滑；按 Shift 或把摇杆推到底时奔跑；跳跃加入“土狼时间”（离开地面后 0.1 秒内仍可起跳）和“跳跃缓冲”；按住跳跃键滑翔（限制下落速度、可以转向），滑翔消耗灯的光芒，站在地上慢慢恢复。
2. 第三人称镜头：平滑跟随；鼠标拖动或右侧手指拖动来旋转；滚轮或双指缩放；镜头不穿进地形；剧情时可以平滑地“看向”某个点。
3. 触屏：左下虚拟摇杆、右侧拖动视角、右下按钮（跳跃/滑翔、姿态、图鉴），两只手可以同时操作。
4. 程序动画：走路时身体起伏、袍子随速度摆动、滑翔时披风张开、灯火随动作摇晃。
5. 设置面板：视角灵敏度、画质（低/中/高）、静音。

验收：手机横屏和竖屏都能顺畅操作；不会卡进地形；掉进深水时回到最后站过的安全位置。
```

## M2 故事系统：只改 JSON 就能做一章

```
任务：
1. 完善章节 schema：beats（id、at 坐标、radius 半径、requires 前置节点、lines、effects、rewards）、cards、relics、scroll、gestures、era（书卷、章、创世纪年或主前/主后年份）。
2. BeatRunner：按顺序或按 requires 触发节点；“引路之光”飞到下一个节点，并在玩家和它之间留下一串光点；触发时显示电影式字幕（上下黑边），点击或空格翻页；每行显示颜色标签和出处。
3. 效果注册表：effects 用字符串引用（如 "world.raiseLand"），每章的场景代码注册自己的效果函数；没有注册的效果在控制台给出中文警告，游戏不崩溃。
4. 时间轴 HUD：左上角显示书卷、章节、年份，节点可以更新它。
5. 写一个只有 JSON、不写任何 TS 的测试章节 content/episodes/test-sandbox.json，证明系统可用。

验收：测试章节能在游戏里从头玩到尾。
```

## M3 收集与图鉴

```
任务：
1. 收集品类型：relic（信物）、scrollPiece（彩窗碎片）、card（知识陶片）、verse（经文之光）、gesture（姿态）、lampStyle（灯的样式）。
2. 世界里的拾取物：发光的小陶片、带特殊光效的信物；靠近自动拾取，有音效和提示；陶片拾取后弹出全文。
3. 图鉴界面（按 B 键或点书本按钮）：彩窗页（每章一扇彩色玻璃窗，没收集的碎片是暗的，集齐后发光并显示经文）、信物页、陶片页（按颜色分类）、经文页（背诵挑战：遮住几个词让玩家选）、姿态页。
4. 存档：localStorage（读写都包在 try/catch 里），带版本号；设置里有“重新开始”。
5. 姿态系统：按键或按钮播放姿态动画。先做“安息”：坐下，镜头慢慢拉远，音乐变轻。

验收：刷新页面后收集进度还在；图鉴在手机上可以滚动，字够大。
```

## M9 同行：联机原型

```
做一个最小的联机原型：
- 服务器：Colyseus（或 PartyKit）房间；用 6 位“团契邀请码”进入，最多 8 人；不需要账号
- 同步：位置、朝向、姿态、灯的亮度
- 预设短语：“平安！”“跟我来”“等等我”“谢谢”“愿主赐福给你”
- 牵手同行：两人靠近，都按“同行”，一人带另一人走
- 为人点灯：靠近别人按“点灯”，两人的灯一起亮一下，成为“同行者”
- 绝对不做自由文字聊天，不保存任何聊天记录
- 在 docs/ 里写清楚部署方法（优先免费方案）和安全说明
```

## 章节策划提示词（给 Claude 或 ChatGPT）

```
你是一位圣经考古学者，也是一位熟悉《光遇》的游戏设计师。我们正在和教会青少年一起做一款面向 8–18 岁孩子的圣经探索游戏《光之踪迹》：玩家是“持灯的见证者”，在开放的小地图中跟随引路之光，见证圣经故事，收集信物、彩窗碎片、知识陶片、经文和姿态。

规则：
- 所有给玩家看的文字都写成 { en, zh } 两份：英文为主，中文辅助。
- 经文英文用 ESV，中文用和合本（新标点和合本，神版），都是原文，必须标出处（写成 Gen 1:3），不改写。不确定原文时写“【待核对】”，不要凭记忆补全；我们会对照 esv.org 和和合本逐字核对。
- ESV 有版权，整个游戏最多 500 节：只选这一章真正需要的经文，长段落可以挑重点节。
- 每一行文字标 kind：scripture（经文）/ history（史地考古，注明“多数学者认为”或“仍有争议”）/ imagination（游戏想象）/ reflection（思考题）。
- 神不以人形出现；暴力“暗示而非展示”。
- 有争议的年代或考古说法，并列不同观点。

请为下面这一章做策划：
- 经文范围：____
- 章节名：____
- 目标时长：__ 分钟
- 我们的章节卡（如有）：____

请输出：
1. 一句话概括和本章情绪
2. 地图概念：地形、地标、引路路线（写成可以画在纸上的描述）
3. 剧情节点 5–8 个：位置、经文（原文 + 出处）、玩家看到什么、轻互动（如有）
4. 收集品：1 个信物、1 扇彩窗（5–7 片，每片对应哪个节点、画什么）、3–6 张知识陶片（至少 2 张考古或历史）、1–3 节金句、0–1 个姿态
5. 敏感内容怎么呈现（如有）
6. 小组讨论题 3 个
7. 视频选题 3 个
8. 按下面的 JSON 格式输出章节数据：
   （把 content/episodes/gen-01-creation.json 的前 40 行贴在这里）
9. 最后列出“需要人工核对”的清单（经文、年代、考古说法）
```
